# KVC Booischot U9 Coach

Publiceer de volledige map op een HTTPS-webhost (GitHub Pages, Netlify of Cloudflare Pages). Open `index.html` niet rechtstreeks vanaf de schijf.

De app gebruikt IndexedDB: gegevens blijven per browser en per webadres op het toestel bewaard.

Lokaal testen: voer in deze map `python -m http.server 8080` uit en open `http://localhost:8080`.

GitHub Pages: maak een lege repository, upload de inhoud van deze map naar de hoofdmap, en kies in **Settings → Pages**: **Deploy from a branch → main → /(root)**. GitHub toont daarna de HTTPS-link.
